翻回本周六天的练习，找一找那个让你「后背一凉」或「原来如此」的场景——那就是你目前最敏感的识别点。
2哪条心法你觉得最难应用？卡在哪里？
是「利益倒推」算不清别人的收益，还是「不透底」总忍不住交底？记下卡点，下周刻意补练。
3本周有没有某个瞬间，你「事后才反应过来」自己本可以用心法识别？
事后诸葛亮不可怕，可怕的是从不复盘。把那个瞬间写下来，它就是下周的实战靶场。
4有没有实践成功（用上了心法并避免了损失）的案例？写下过程。
哪怕只避免了一笔小亏，也值得记下来——成功经验是最牢固的行为锚点。
5下周你最想刻意练习哪条心法？准备在什么场景用？
选一条，绑一个具体场景（如「下次谈价前先设心理区间」），下周每天在练习里盯着它。
6给本周的自己打几分（1-10）？为什么？
打分不是评价，是校准：低分找差距，高分别松懈，分数要配上理由。

周一 · ①默认预设 / ②利益倒推 / ③警觉信号
默认对方有立场再交朋友；别听他要什么，看谁得利；反常即成串，急事缓办。
周二 · ④信息不对称 / ⑤零和默认 / ⑥留一手
先补信息再表态；分蛋糕前先看蛋糕多大；牌不打完、话不说绝。
周三 · ⑦不透底 / ⑧测试代替信任 / ①默认预设
底牌亮出即失效；承诺免费、行为付费；先当对手算，再当朋友处。
周四 · ③警觉信号 / ⑥留一手 / ②利益倒推
信号要成串；退路提前铺；谁获益谁推动。
周五 · ④信息不对称 / ⑦不透底 / ⑤零和默认
「我以为」最贵；给区间不给底价；把分配规则写清楚再点头。
周六 · ⑧测试代替信任 / ①默认预设 / ④信息不对称（综合）
综合考察：小测试见真章；他图什么优先；同一件事两套报价，先验证再决定。

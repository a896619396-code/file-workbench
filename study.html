数据管理

数据保存在本浏览器 localStorage 中，跨设备请用「导出备份 / 导入备份」迁移。清空操作需二次确认，且不会删除服务器上的资料。
💡 使用说明
1️⃣ 资料库：先到「资料库 / 设置」导入你的学习资料（或点「导入全部」），每篇自动生成复习卡，eq / xinfa 还会生成「可检索的场景话术」。
2️⃣ 复习：每天打开「复习」，按遗忘曲线把到期的卡过一遍，四档评分决定下次间隔（忘记→1天，困难→保持，良好→翻倍，轻松→翻倍跳档）。
3️⃣ 进度：复利曲线记录你的每日投入与累计掌握，坚持不断，曲线会向上加速。
4️⃣ 问题解决：遇到具体困境时输入描述，系统匹配职场情商 / 心法场景，给出识别要点与参考话术。
5️⃣ 弱点练习：系统根据你的错题自动挑出薄弱卡，AI 可深度诊断给针对性练习。
6️⃣ AI 答疑：配置 API Key 后，可以就导入的资料直接提问。
数据都在本地，可随时导出备份。
